# Fallback: audit from exports

Use only when Composio can't connect. The audit is manual: you apply `audit-signals.md` yourself to what the owner pastes or uploads, so say it's less complete than a live audit.

Ask for one export at a time. For each: Google Ads → the page below → date range **Last 30 days** → columns icon → add the listed columns → download icon → CSV (or paste the table).

1. **Campaigns** (left menu: Campaigns). Columns: Campaign, Status, Campaign type, Budget, Bid strategy type, Cost, Clicks, Impressions, Conversions, Conv. value, Cost / conv., Search impr. share, Search lost IS (budget), Search lost IS (rank).
   Feeds areas 3, 5, 6 and the goal. If any campaign is Performance Max, also ask for the Asset groups table with Ad strength.
2. **Keywords** (Campaigns → Audiences, keywords and content → Search keywords). Columns: Keyword, Match type, Campaign, Ad group, Status, Quality Score, Exp. CTR, Ad relevance, Landing page exp., Cost, Conversions, Impressions.
   Feeds areas 9 and 10.
3. **Search terms** (Campaigns → Insights and reports → Search terms). Columns: Search term, Match type, Added/Excluded, Campaign, Cost, Clicks, Conversions.
   Feeds area 11: the waste list and the Lin-Rodnitzky ratio.
4. **Ads** (Campaigns → Ads). Columns: Ad type, Campaign, Ad group, Status, Ad strength, Final URL, Headlines, Descriptions, Cost.
   Feeds areas 12 and 14.
5. **Assets** (Campaigns → Assets, table view). Columns: Asset type, Level, Campaign, Status.
   Feeds area 13.

Then ask in one message: conversion actions (Goals → Conversions → Summary: name, primary/secondary, count, value), location option (presence or presence-or-interest), networks on each Search campaign, ad schedule, shared negative lists and where they're applied, customer lists, and the ask-owner questions from `audit-signals.md`.

Score each signal you can judge, mark the rest "not measured", and write the report in the same shape as a live audit, with "Data source: exports pasted by the owner" at the top.
