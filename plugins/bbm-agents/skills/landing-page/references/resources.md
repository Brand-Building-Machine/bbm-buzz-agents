# Free resources

Everything the method needs is free. Paid or community-gated tools are optional extras, used only with the owner's yes. Check each resource is still available; these were checked in September 2026.

## Reference galleries (step 3)

- recent.design (formerly godly.website): curated recent sites.
- savee.com: visual bookmarking, strong on art direction.
- design-inspo-bay.vercel.app: a 40-site index of galleries, UI patterns, type and brand resources (entries are leads, not endorsements).
- land-book.com, lapa.ninja, onepagelove.com: landing page galleries (free browsing).
- For small local businesses: search the business's own category and city and look at the top-ranked real competitors; the winners in the niche are references too.
- refero.design: large UI reference library; free depth not verified.

## Components and motion

- 21st.dev: component library with copyable prompts (free tier). Restyle to the brand tokens; never ship its defaults.
- motionsites.ai: motion section previews (paid artifacts are optional).

## Icons (pick one set per page, never mix)

- Lucide (lucide.dev), Heroicons (heroicons.com), Phosphor (phosphoricons.com): free, open licence.

## Fonts (only when the brand has none)

- Google Fonts, Fontshare (fontshare.com), Open Foundry. Check the licence allows commercial web use.

## QA

- The `page-qa` skill (this plugin): static checks, overflow at 4 widths, screenshots.
- Lighthouse (built into Chrome DevTools) for LCP/CLS.

## Optional, gated or paid (never required)

- Image/video generation (e.g. Higgsfield, OpenArt): owner's own account, pilot one image first.
- Relume (sitemaps and wireframes): the method's markdown sitemap + grey-box wireframe step replaces it.
- Community-gated creator skills (Design Loop, ScrollCraft): not available to us; the fresh-context critic step covers the same ground.
