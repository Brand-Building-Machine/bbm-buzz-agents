# The audited section set

**The single source of truth for which sections the sales-page audits cover.** The light, deep and 5-wins audits all use this set, and none of them carries its own copy.

**Map the copy to these by FUNCTION, never by looking for labels.** Not every page has every section, and it is not supposed to. Judge relevance per the engine's set-aside rules and each mode's section-specific handling notes.

**Doctrine files live in `.brain/sales-page/doctrine/`.**

## Notes on two of them

**Competitive comparison is OPTIONAL and set aside when absent.** Judge it where a page runs one; **never count its absence as a gap and never suggest adding one.** A page with no named rivals to compare against is a normal page, so this section has zero effect on the score unless it is actually present.

**The lead is near-universal and scores like any other section.** Its own doctrine calls it make-or-break and says to spend more editing time on it than anything else; **that is writing guidance and not a scoring instruction.** No multiplier, no extra weight.
